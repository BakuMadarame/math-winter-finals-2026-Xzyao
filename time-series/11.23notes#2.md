# Holt 两参数指数平滑（Holt's Two-Parameter Exponential Smoothing）

## 1. 适用场景

Holt 两参数指数平滑适用于**含有线性趋势**的序列预测。其基本思想是：具有线性趋势的序列通常可以表达为如下模型结构。

$$x_t = a_0 + bt + \varepsilon_t$$

其中 $a_0$ 为截距，$b$ 为斜率（每期固定增量），$\varepsilon_t$ 为随机扰动项。

## 2. 等价表达

对 $bt$ 做拆分 $bt = b(t-1) + b$：

$$x_t = a_0 + b(t-1) + b + \varepsilon_t$$

由 $t-1$ 时刻的模型 $x_{t-1} = a_0 + b(t-1) + \varepsilon_{t-1}$ 可得

$$a_0 + b(t-1) = x_{t-1} - \varepsilon_{t-1}$$

代入并整理：

$$
\begin{aligned}
x_t &= a_0 + b(t-1) + b + \varepsilon_t \\
    &= \left(x_{t-1} - \varepsilon_{t-1}\right) + \left(b + \varepsilon_t\right) \\
    &= a(t-1) + b(t)
\end{aligned}
$$

## 3. 符号含义

- $a(t-1)$：序列在 $t-1$ 时刻**截距（水平）**的无偏估计值；
- $b(t)$：序列在 $t$ 时刻**斜率（趋势）**的无偏估计值。

即 $x_t$ 被分解为"上一期的水平估计 + 本期的趋势估计"两部分，这正是"两参数"的由来。

## 4. 为什么要做这个分解

原始模型 $x_t = a_0 + bt + \varepsilon_t$ 中的 $a_0, b$ 是**全局常数**，需要用整段数据一次性拟合（如最小二乘）。而等价形式把 $x_t$ 写成两个**随时间更新的局部量**之和：

- 水平 $a(t)$ 描述"现在大概在哪"；
- 趋势 $b(t)$ 描述"每期变化多少"。

这样就能用递推（在线）方式随新观测滚动更新，无需重新拟合全部历史，也允许趋势本身随时间缓慢变化。

## 5. Holt 递推公式（补充）

引入平滑系数 $\alpha, \beta \in (0,1)$：

$$
a_t = \alpha x_t + (1-\alpha)(a_{t-1} + b_{t-1})
$$

$$
b_t = \beta (a_t - a_{t-1}) + (1-\beta) b_{t-1}
$$

向前 $h$ 步预测：

$$\hat{x}_{t+h\mid t} = a_t + h\, b_t$$

- $a_{t-1} + b_{t-1}$ 是对 $x_t$ 的"先验"预测，$\alpha$ 越大越相信新观测；
- $a_t - a_{t-1}$ 是本期的趋势增量，$\beta$ 越大趋势调整越灵敏。

## 6. 注意事项

1. 第 3 节中的"无偏"是理想化表述：实际 Holt 递推给出的是**指数加权**估计，存在滞后偏差，只有在线性趋势严格成立且扰动为零均值时才近似无偏。
2. 该模型只处理**趋势**，不含季节项；含季节性需用 Holt-Winters（三参数）方法。
3. 初值 $a_0, b_0$ 的选取会影响前期拟合，常用前若干期回归或均值/差分初始化。
4. 长期外推时 $\hat{x}_{t+h\mid t}$ 随 $h$ 线性发散，预测区间应随 $h$ 增大而变宽。
